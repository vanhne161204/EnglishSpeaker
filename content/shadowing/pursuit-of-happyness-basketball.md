### Useful phrases

| Phrase | Meaning | Note |
|---|---|---|
| go pro | trở thành vận động viên chuyên nghiệp | *pro* = professional |
| about as good as | giỏi ngang với | so sánh bằng |
| below average | dưới trung bình | |
| excel at something | rất giỏi việc gì | |
| day and night | suốt ngày đêm | |
| not even me | kể cả bố | nhấn mạnh |
| gotta = got to | phải | văn nói |
| wanna = want to | muốn | văn nói |
| Period. | Vậy thôi / Chấm hết. | kết thúc ý, không bàn thêm |
